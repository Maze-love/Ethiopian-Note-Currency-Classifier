# Ethiopian Banknote Currency Classifier

This project uses Deep Learning (CNN) to identify Ethiopian banknote denominations and provides a voice announcement of the result in Amharic. It includes a training pipeline in Jupyter Notebook and a web-based inference interface using Gradio.

## 🚀 Features

- **Denomination Support**: Recognizes 5, 10, 50, 100, and 200 Birr notes.
- **Voice Feedback**: Uses Google Text-to-Speech (`gTTS`) to announce the currency in Amharic.
- **Web Interface**: User-friendly Gradio UI for uploading images and getting instant results.
- **Training Pipeline**: Comprehensive notebook covering data augmentation, class weighting for imbalance, and model evaluation.

## 🛠️ Tech Stack

- **Deep Learning**: TensorFlow / Keras (CNN)
- **UI Framework**: Gradio
- **Audio**: gTTS (Google Text-to-Speech)
- **Data Processing**: NumPy, Pillow, Scikit-learn
- **Visualization**: Matplotlib

## 📋 Prerequisites

- Python 3.10+
- A trained model file named `ethiopian_currency_model.keras` (generated by the notebook)

## 🔧 Installation

1. **Clone the repository**:

   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## 📖 Usage

### 1. Training the Model

If you need to retrain the model or explore the data analysis:

- Open `Image_note_currency.ipynb` in Jupyter Notebook or VS Code.
- Ensure your dataset is organized in `dataset/Ethiopian_Currency/`.
- Run all cells to train and save the `.keras` model.

### 2. Running the Web App

To launch the interactive classifier:

```bash
python app.py
```

Once running, open the local URL (usually `http://127.0.0.1:7860`) in your browser to upload images and hear the audio predictions.

## 📁 Project Structure

- `app.py`: The Gradio web application for inference.
- `Image_note_currency.ipynb`: Data preprocessing, model architecture, and training logic.
- `requirements.txt`: Necessary Python libraries.
- `ethiopian_currency_model.keras`: The saved trained model (generated after training).
